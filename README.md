# Senior Help - Vizag
Problem 5 - Senior Citizen Emergency Help - GVP Gen AI Ignite Hackathon

## Problem
Senior citizens ki emergency lo ambulance, pharmacy, doctor number dorakadam kastam. Small font, login, confusion.

## Solution
3 PEDDA Buttons matrame - No Login - No Search
1. AMBULANCE - 108 ki direct call
2. PHARMACY - Ippudu open unna nearest pharmacy
3. DOCTOR - Emergency doctor

## Features
- Telugu Voice - Button press cheste Telugu lo cheptundi
- Night Filter - Ippudu open unna pharmacy matrame chupistundi
- Big Font - Senior citizens kosam pedda letters
