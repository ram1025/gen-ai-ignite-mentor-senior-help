# 🙏 Senior Help - MVP Vizag
**Problem 5 - Senior Citizen Emergency Help - GVP Gen AI Ignite Hackathon**

**One Click = One Call | For Seniors of MVP Colony, Vizag**

## 🎯 Problem
Senior citizens ki emergency lo ambulance, pharmacy, doctor number dorakadam kastam. Small font, login, confusion.
- Number save cheyadam / type cheyadam kashtam
- Emergency lo Google lo search cheyaleru
- Chinna buttons - Kanipinchavu, nokkaleru
- Family ki call cheyadam late avuthundi

## ✅ Solution
**PEDDA Buttons matrame - No Login - No Search - No Typing**
1. **AMBULANCE - 108** ki direct call
2. **PHARMACY - Apollo MVP** - Ippudu open unna nearest pharmacy
3. **DOCTOR - 104 Govt Free** - Emergency doctor
4. **HOSPITAL - Medicover MVP** - Emergency
5. **FAMILY SOS - 88869 92983** - Direct call to family
6. **WHATSAPP PHARMACY** - Medicine order without typing

## ✨ Features
- **Telugu Voice** - Button press cheste Telugu lo cheptundi
- **Night Filter** - Ippudu open unna pharmacy matrame chupistundi
- **Big Font** - Senior citizens kosam pedda letters
- **Telugu / English Toggle** - Andariki easy
- **WhatsApp Pharmacy** - Ready message tho medicine order
- **Maps** - Near Pharmacy / Hospital location
- **Family SOS Shortcut** - Home screen long-press cheste direct SOS
- **PWA App** - Android + iOS lo App laga pani chestundi, Play Store avasaram ledu
- **Portrait Mode** - Phone tilt ayina same easy view

## 🔍 Research & Existing Solutions
- Google / JustDial lo search cheyali - Senior ki kashtam
- Vere health apps lo login, small font, ads ekkuva
- Maa solution lo - No Login, No Ads, Only Big Buttons, Real MVP numbers
